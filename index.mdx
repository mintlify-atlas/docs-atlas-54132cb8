## Why LLM Gateway Core?

LLM Gateway Core provides reliable, cost-effective access to multiple LLM providers with intelligent routing, distributed caching, atomic rate limiting, and comprehensive observability. Built on FastAPI with Redis and Prometheus integration.

<CardGroup cols={2}>
  <Card title="Multi-Provider Support" icon="network-wired">
    Abstract Gemini, Ollama, and custom providers behind a single API
  </Card>
  <Card title="Intelligent Routing" icon="route">
    Route requests based on model hints: online, local, fast, or secure
  </Card>
  <Card title="Distributed Caching" icon="database">
    Redis-backed response caching to reduce latency and API costs
  </Card>
  <Card title="Rate Limiting" icon="gauge">
    Token bucket algorithm with atomic Redis operations
  </Card>
</CardGroup>
